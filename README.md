# Taller 1 POO

Este proyecto consiste en la creación de un sistema cono el fín de gestionar actividades para cada usuario, permitiendo a estos:

- Iniciar sesión  
- Registrar  
- Modificar actividades  
- Eliminar actividades  

Sumado a la posibilidad de hacer un análisis de estas, obteniendo información tal como:

- Actividad más realizada.  
- Actividad más realizada por usuario.  
- Usuario con mayor tiempo de ocio (procrastinación).  
- Visualización completa de actividades.  

("Toda la información se almacenará en 2 archivos ("Usuarios.txt" y "Registros.txt")")

Empleando arreglos como estructura de almacenamiento para lograr la lectura y escritura de archivos con el fín de lograr una persistencia de los datos.
